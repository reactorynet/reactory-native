## 🎨 Architecture Decisions Log

### August 17, 2025
**Decision**: Use EventEmitter pattern for ReactorySDK  
**Rationale**: Matches PWA client architecture, enables decoupled communication  
**Impact**: Consistent API between web and mobile clients  

**Decision**: Adapt component proxy pattern to React Native  
**Rationale**: Maintains server-driven UI capability  
**Impact**: Form definitions can be shared between platforms  

**Decision**: Use AsyncStorage for client configuration  
**Rationale**: Secure, performant local storage for React Native  
**Impact**: Multi-client support works offline
